# Tra Từ Tiếng Trung

Trang tra cứu từ tiếng Trung giản thể: pinyin, giọng đọc, âm Hán Việt, nghĩa tiếng Việt và câu ví dụ.
Mỗi từ có link riêng để chia sẻ, dạng `?w=你好`.

- Thêm từ: sửa `js/words.js`.
- Chạy thử ở máy: `powershell -ExecutionPolicy Bypass -File serve.ps1` rồi mở http://localhost:8080
